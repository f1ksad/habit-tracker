# Habit Tracker on Python

Это простая консольная программа для отслеживания ежедневных привычек.

## Что умеет программа:
* Показывать список привычек со статусами выполнения `[ ]` и `[V]`.
* Добавлять новые привычки в список.
* Отмечать привычки как выполненные.
* Сбрасывать все галочки в начале нового дня.

## Как запустить:
1. Убедитесь, что у вас установлен Python.
2. Скачайте файл `habit_tracker.py`.
3. Запустите его через терминал командой: `python habit_tracker.py` или зайдите в папку Russian edition потом зайдите в папку dist и запустите habit_tracker
